### Overview

Eclipse is the enterprise core system that powers LB Finance PLC's business operations. It is a large, mission-critical platform handling deposits, general ledger transactions, customer management, and more. I joined as an Intern Software Engineer and was later promoted to Associate Software Engineer, spending just over a year as a full-stack developer on two of the system's core modules.

This was my first professional experience in tech, and it taught me more about writing real software for real business operations than anything else could have.

### The Context

![LB Finance Logo](/project-images/LB-image-cropped.jpg "LB Finance PLC")

LB Finance is one of Sri Lanka's largest licensed finance companies. Eclipse is the system where most of business processes runs on. Working on it meant understanding that every change had consequences, that SQL procedures touching production data needed to be right the first time, and that clean, maintainable code wasn't just a best practice, it was a necessity when dozens of engineers are working on the same codebase.

### What I Did

**Deposit Module**
- Developed frontend components in Angular for several deposit account management workflows.
- Built and maintained backend services using ASP.NET, following established design patterns and clean coding standards.
- Designed and optimized SQL Server stored procedures and functions for efficient data retrieval and processing.
- Applied Clean Code principles and Test-Driven Development (TDD) practices to improve code quality and maintainability.

**General Ledger Module**
- Contributed to GL transaction processing features, ensuring data consistency across accounting entries.
- Worked on reporting components that surfaced GL data for finance and operations teams.

**Engineering & Team Contributions**
- Conducted tech talks for the broader engineering team, presenting on development techniques and tooling.
- Supported and mentored intern engineers through knowledge-sharing sessions and code reviews.
- Collaborated within an Agile environment — participated in sprint ceremonies and coordinated with cross-functional teams including QA and business stakeholders

### Tools & Technologies

Angular · ASP.NET · SQL Server · Git · Azure DevOps

### Outcome

Completed a successful 12-month tenure moving from intern to associate engineer. Delivered multiple features across the Deposit and General Ledger modules, all of which went into production on the live system. The experience of working on a high-stakes enterprise system early in my career gave me a strong engineering foundation that directly shapes how I work as a Business Analyst today and I understand what good requirements look like to a developer because I was **one**.
